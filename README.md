# 5026CMD
Web-Based Restaurant Reservation and Order Management System

## Role permissions (US06)

Administrators inherit all restaurant staff functions, including reservation management, seating, check-in, order processing, and billing, in addition to administrator-only management and reporting. Customers can access their own reservations and orders. Staff cannot access administrator-only pages.

Administrator actions use the same service validation as staff: table availability, successful deposit payment, cancellation forfeiture, minimum spending, and the one-change modification deadline still apply. Administrator access does not bypass business rules.
